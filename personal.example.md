# Personal rules (copy to personal.md)

CLAUDE.md imports `@personal.md`, so anything you put there is loaded on every
request. personal.md is untracked (see .gitignore) and a missing file is harmless.
Put rules here that only apply to your machine, shell or habits, so the shared
CLAUDE.md stays portable.

- Example: On this machine, run repo scripts with the Bash tool, never inside PowerShell.
- Example: Keep answers short; ask before touching anything under ~/work/billing.
